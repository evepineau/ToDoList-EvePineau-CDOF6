# ToDoList-EvePineau-CDOF6

## Description
A console-based application to help keep track of tasks. You should be able to add, delete, and complete tasks.

## How to Run the Project
### Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/your-username/ToDoList-EvePineau-CDOF6.git
   cd ToDoList-EvePineau-CDOF6
   ```

2. Ensure you have Python 3.x installed on your machine.

### Execution

To run the project, use the following command:

```sh
python ToDoList.py
```

### Usage

Once the script is executed, you will see a menu with the following options:

1. Add a task
2. Delete a task
3. Modify a task
4. Toggle task completion
5. Quit the script

Follow the on-screen instructions to interact with the application.
